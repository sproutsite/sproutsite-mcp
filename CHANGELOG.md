# Changelog

## 0.1.0 (2026-11-21)

- Add a read-only MCP server over Streamable HTTP with English and German documentation search, page retrieval, and component lookup.
- Support self-hosting with Docker Compose and validated runtime snapshots that can be switched or rolled back without rebuilding the image.
- Document local and self-hosted client connections and license the server under Apache-2.0.
